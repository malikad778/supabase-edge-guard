# Code of conduct

We want this project to be a welcoming place for everyone who contributes.

- Be respectful. Disagree with ideas, not people.
- Assume good faith; ask before assuming intent.
- No harassment, discrimination, or personal attacks, in any form.
- Keep discussion on topic and constructive; critique code and rules, not the author.

Maintainers may remove comments, close issues, or block users who violate these expectations.
Report concerns privately to the maintainer through the contact on the GitHub profile.
