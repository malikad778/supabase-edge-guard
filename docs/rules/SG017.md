# SG017 - PublicEnvSecretOrUnignoredEnv

**Severity:** error · **Layer:** config · **Auto-fix:** none

> Secret-looking variable with a public prefix (NEXT_PUBLIC_/VITE_/PUBLIC_), or .env files not git-ignored.

## Why it matters

Variables prefixed NEXT_PUBLIC_, VITE_ or PUBLIC_ are inlined into the browser bundle by design. Naming a secret that way publishes it. Committing .env / .env.local publishes it through version control instead.

## Bad

```text
NEXT_PUBLIC_SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...
```

## Good

```text
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...   # no public prefix, read only on the server
# .gitignore
.env*.local
```

## Suppressing

Only suppress after you have confirmed the finding is a false positive. A reason is mandatory; suppressions without one are ignored and reported as `SG000`.

```
// edge-guard-disable-next-line SG017 -- <why this is safe>
```

In SQL files use `-- edge-guard-disable-next-line SG017 -- <reason>`. Use `edge-guard-disable-file` to cover a whole file, or set `"rules": { "SG017": "off" }` in the config.
