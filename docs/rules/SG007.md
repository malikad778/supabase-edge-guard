# SG007 - MissingIndexOnPolicyOrFkColumn

**Severity:** warning · **Layer:** sql · **Auto-fix:** safe

> Foreign-key column or column used in an RLS policy has no index.

## Why it matters

RLS predicates such as user_id = auth.uid() run on every query. Without an index on that column Postgres scans the whole table for each request; the same applies to foreign keys on joins and cascading deletes. The slowdown appears only once the table grows.

## Bad

```sql
create table public.notes (id uuid primary key, user_id uuid references auth.users(id));
-- no index on user_id
```

## Good

```sql
create index if not exists idx_notes_user_id on public.notes (user_id);
```

## Suppressing

Only suppress after you have confirmed the finding is a false positive. A reason is mandatory; suppressions without one are ignored and reported as `SG000`.

```
// edge-guard-disable-next-line SG007 -- <why this is safe>
```

In SQL files use `-- edge-guard-disable-next-line SG007 -- <reason>`. Use `edge-guard-disable-file` to cover a whole file, or set `"rules": { "SG007": "off" }` in the config.
