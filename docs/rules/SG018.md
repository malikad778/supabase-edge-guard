# SG018 - LlmCallWithoutLimits

**Severity:** warning · **Layer:** ts · **Auto-fix:** none

> Server-side LLM call with no timeout, max duration or rate limit in the same file.

## Why it matters

An unauthenticated or unthrottled route that forwards prompts to a paid LLM API is a billing-drain endpoint: one script can burn the monthly budget in minutes, and a hung upstream request can pin serverless functions until they time out.

## Bad

```ts
export async function POST(req: Request) {
  const { prompt } = await req.json();
  return streamText({ model: openai('gpt-4o'), prompt }).toDataStreamResponse();
}
```

## Good

```ts
export const maxDuration = 30;
export async function POST(req: Request) {
  const { success } = await ratelimit.limit(ip);
  if (!success) return new Response('Too many requests', { status: 429 });
  ...
}
```

## Suppressing

Only suppress after you have confirmed the finding is a false positive. A reason is mandatory; suppressions without one are ignored and reported as `SG000`.

```
// edge-guard-disable-next-line SG018 -- <why this is safe>
```

In SQL files use `-- edge-guard-disable-next-line SG018 -- <reason>`. Use `edge-guard-disable-file` to cover a whole file, or set `"rules": { "SG018": "off" }` in the config.
