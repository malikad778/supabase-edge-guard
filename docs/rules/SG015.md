# SG015 - UpdatePolicyWithoutWithCheck

**Severity:** warning · **Layer:** sql · **Auto-fix:** none

> UPDATE/ALL policy has USING but no explicit WITH CHECK on an ownership column.

## Why it matters

Without an explicit WITH CHECK, Postgres reuses USING for the new row. That usually matches intent, but ownership policies are easy to loosen later (for example by adding an OR branch to USING), and then a user can update a row they own and reassign user_id to someone else. An explicit WITH CHECK states the invariant for the new row.

## Bad

```sql
create policy "own rows" on public.notes for update using (user_id = (select auth.uid()));
```

## Good

```sql
create policy "own rows" on public.notes for update
  using (user_id = (select auth.uid()))
  with check (user_id = (select auth.uid()));
```
