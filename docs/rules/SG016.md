# SG016 - EdgeFunctionVerifyJwtDisabled

**Severity:** warning · **Layer:** config · **Auto-fix:** none

> Edge function has verify_jwt = false and no Authorization / webhook-signature check in its code.

## Why it matters

verify_jwt = false makes the Supabase gateway skip JWT verification, which is correct for webhooks - but only if the function authenticates the caller itself. Otherwise it is an unauthenticated endpoint, often running with the service_role key.

## Bad

```text
# supabase/config.toml
[functions.sync-users]
verify_jwt = false
// index.ts never inspects the request headers
```

## Good

```text
// verify a shared secret or signature before doing any work
if (req.headers.get('x-webhook-secret') !== Deno.env.get('WEBHOOK_SECRET')) return new Response('forbidden', { status: 403 });
```

## Suppressing

Only suppress after you have confirmed the finding is a false positive. A reason is mandatory; suppressions without one are ignored and reported as `SG000`.

```
// edge-guard-disable-next-line SG016 -- <why this is safe>
```

In SQL files use `-- edge-guard-disable-next-line SG016 -- <reason>`. Use `edge-guard-disable-file` to cover a whole file, or set `"rules": { "SG016": "off" }` in the config.
