# State of Supabase security

This report is generated, not written by hand. Clone the repositories you want to measure, then run:

```bash
pnpm tsx scripts/bench-public.ts /path/to/clones --out docs/state-of-supabase-security.md
```

The script scans each repository offline and writes the per-rule and per-repository tables. No figures are published here until you generate them from the repositories you chose.
